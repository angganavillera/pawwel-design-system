Tier 2 · Semantic

Background Tokens

Semantic background tokens define surface hierarchy. Always use these — never raw primitives — in components.

Token Resolves to Value Usage
color.bg.primary brown.white #ffffff Root app background. Never use inside elevated cards.
color.bg.secondary brown.10 #f7f4f2 Card surfaces, section backgrounds. Most-used surface.
color.bg.tertiary brown.20 #e8ddd9 Nested card backgrounds, inset surfaces.
color.bg.quaternary brown.30 #d6c2b8 Deeply inset surfaces, placeholder backgrounds.
color.bg.primary-alt gray.10 #f5f5f5 Cool-neutral alternative surface for settings screens.
color.bg.active orange.60 #ea580c Active/selected states, primary CTA backgrounds.
color.bg.primary-solid brown.100 #251404 Dark solid surfaces — primary button, robot card bg.
color.bg.secondary-solid brown.80 #4f3422 Secondary dark surface — sheet handles, dark chips.
color.bg.disabled gray.20 #e1e1e0 Disabled button/input background.
color.bg.overlay brown.100-a64 rgba(37,20,4,0.64) Modal overlay, scrim behind bottom sheets.
Tier 2 · Semantic

Foreground Tokens

Text and icon color hierarchy. Four tiers (primary → quaternary) create natural visual rhythm without manual opacity hacks.

Token Resolves to Value Usage
color.fg.primary brown.100 #251404 Page titles, primary labels. Maximum contrast.
color.fg.secondary brown.80 #4f3422 Section headings, important body text.
color.fg.tertiary brown.60 #926247 Supporting text, descriptions, secondary labels.
color.fg.quaternary brown.40 #c0a091 Timestamps, placeholders, meta info.
color.fg.white brown.white #ffffff Text on dark/solid surfaces (buttons, robot card).
color.fg.disabled gray.40 #aca9a5 Disabled text, inactive tab icons.

Use borders sparingly. PAWWEL's aesthetic is air and warmth — use shadow and layering for depth before reaching for borders.

Semantic Tokens

Text Color Tokens

Semantic text color tokens define the full palette of text colors available across the PAWWEL UI — from neutral brown and gray scales to emotional state colors for each mood context. These tokens are scoped to text fills only and should never be applied to backgrounds or borders.

💡
Usage principle
Use color.text.heading for all primary headings, color.text.body for body copy, and emotional color tokens (e.g. color.text.green.60) only when text must reflect the pet's current emotional state. Never use primitive tokens directly — always reference via color.text.*.

Accessibility note
Always verify contrast ratio when using light shades (10–40) on white backgrounds. color.text.yellow.* and color.text.green.10–30 may fail WCAG AA — pair with a supporting background tint or use darker shades for text.
